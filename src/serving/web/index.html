Project Purpose

NovaLM-Hybrid combines a mini language model with retrieval grounding. Use Pure mode for baseline generation, and Hybrid mode to inject top relevant context chunks before answering.

Why this is valuable

  • Demonstrates end-to-end AI engineering, not only model training.
  • Provides API + UI + history + export for real usage and evaluation.
  • Supports repeatable demos with measurable latency and retrieval context.

Recommended flow

  • Enter prompt and choose generation mode.
  • Inspect outputs and retrieved contexts.
  • Use history filters/export to compare quality over runs.
